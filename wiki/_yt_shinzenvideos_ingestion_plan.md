## Gate Rule

Run one small gate at a time:

1. Create exactly one source page per substantive selected video.
2. Update only the owner pages that the source actually changes.
3. Decide whether a synthesis, thesis, question, or current-model update is
   warranted; do not create one merely because a gate completed.
4. Update `wiki/index.md`, `wiki/log.md`, and the page catalog if a compiled
   page is created.
5. Run `tools\wiki_lint.cmd`.
6. Reassess before starting the next selected video.

The checkpoint question is:

> What did this channel item make future agents able to notice, route,
> explain, protect, or transmit better than the existing compiled wiki?

Under the current inclusionary policy, that checkpoint is used to shape the
source page and owner-page updates, not to reject different Shinzen-primary
practice/wisdom talks merely for topical overlap.
