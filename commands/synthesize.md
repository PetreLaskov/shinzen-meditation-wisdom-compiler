# synthesize

Use when creating a synthesis, thesis, or durable map from existing pages.

1. Read relevant page cards and bodies.
2. Name the through-line in one sentence.
3. Stop if there is no real through-line.
4. Write the page from `wiki/_templates.md`.
5. Include tensions, boundaries, dependencies, and open frontiers. When the
   synthesis depends on Shinzen lectures, preserve the teaching handles and
   phenomenological discriminations, not only the propositional model.
6. Update Related edges, index, and log.
7. Run `python tools/wiki_lint.py`, or `tools\wiki_lint.cmd` on this
   Windows/Codex workspace.
