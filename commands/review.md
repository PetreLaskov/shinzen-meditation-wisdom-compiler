# review

Use for periodic wiki maintenance.

1. Run lint.
2. Inspect orphans, high-importance seeds, singleton tags, bloated pages,
   stale pages, unresolved questions, contested claims, epistemic debt, and
   index shape. Include startup-context pressure: index length, log-loading
   habits, frontmatter manifests, and duplicated chronology across system
   files. For Shinzen lecture work, also inspect whether teaching moves have
   been flattened into generic claims and whether the Teaching Transmission
   domain has enough routing support.
3. Fix small local issues safely.
4. Defer large refactors with a clear note.
5. Refresh the dashboard and shape paragraph if stale.
6. Append one `review` log entry.
