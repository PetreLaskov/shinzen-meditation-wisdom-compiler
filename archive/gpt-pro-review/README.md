# GPT Pro Review Pack

This folder is a self-contained context sample for a GPT-5.5 Pro review of the
Shinzen Meditation-Wisdom Compiler wiki.

Use `PROMPT.md` as the instruction prompt, then attach or paste the files listed
in `MANIFEST.md`. The folder preserves original relative paths so the reviewer
can reason about routing, source references, and lint diagnostics without seeing
the entire wiki.

Core intent: audit this as an epistemic operating system for future agents, not
as a normal wiki, transcript archive, Buddhism encyclopedia, or Shinzen fan
site. The optimization target is better future practice reasoning per token
loaded.

Included:

- Operating contract and workflow files.
- Current index, log, templates, shape guidance, and lint code.
- Current whole-system model plus representative high-value concept/synthesis
  pages.
- Source-page samples with matching raw files for fidelity checking.
- Lint-stress pages flagged for oversized `sources` frontmatter.
- Fresh lint output from 2026-05-12.
